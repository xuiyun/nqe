# NQE ｜ 原生提问增强

> **先看三行**
> - 需要 **DSH**（DeepSeek Harness）带 Web 界面；插件是标准 bundle，装完**刷新页面**就能用，只改到宿主半边时才需要重启。
> - 装的时候用 `dsh plugin --profile desktop add github:你的名字/nqe`（网页端把 `desktop` 换成 `web`）。
> - 关掉「提问窗口优化」就退回系统原生的提问卡，界面跟没装插件时一模一样 —— 随时能一键退回去。

DSH 插件：**给提问窗口换一套更顺手的皮** —— 可翻页、可跳过、能边选边打字贴图，还能让 AI 动手前先跟你对一遍理解。

## 它做什么

| | 说明 |
|---|---|
| **能翻页** | 一次问好几件事时，一屏一题，右上角翻页；实在不想答就点「跳过」 |
| **能收起** | 问完了点右上角箭头，整张卡收成一行，不挡着你看对话 |
| **想怎么答都行** | 点选项、直接打字、把截图往输入框一贴 —— 三种都算答案，一起交上去 |
| **右下角那颗键就是提交** | 提问期间它会变成蓝底白箭头，选完点一下即交；没选也没打字的时候它不动 |
| **动手前先对一遍理解** | AI 不会听到要求就闷头做，先把理解说一遍问你「这么理解对吗」，你确认或改完再开工（可关） |
| **选完自动翻页** | 开了之后选完自动跳下一题；同一页换答案不会乱跳（可关） |

## 装之前

- DSH 已经能正常打开（桌面端 / 网页端都行）
- 插件装在 profile 里：桌面端一般是 `desktop`，网页端是 `web`

## 装

### 一、从 GitHub 装（推荐，跟版本走）

```
dsh plugin --profile desktop add github:你的名字/nqe
```

### 二、本地目录装

```
dsh plugin --profile desktop add D:\你的路径\nqe
```

装完刷新页面；如果设置页里没出现，重启一次 DSH。

## 设置里有三个开关

设置 → 插件 → **NQE｜原生提问增强**。

| 位置 | 开关 | 作用 |
| --- | --- | --- |
| 提问模式 | **提问模式** | 总开关。关掉之后 AI 不再追问，也不需要你确认 |
| 提问模式 | └ **执行操作前向用户确认理解是否正确** | 动手前先把理解讲清楚问你一句（默认开） |
| 提问窗口优化 | **提问窗口优化** | 开：用这套新面板；关：退回系统原生提问卡 |
| 提问窗口优化 | └ **选择答案后自动翻页** | 选完自动跳下一题；同一页换答案不会跳 |

有额外设置的开关，右边会多一个箭头，点开才看到下面那条，平时不占地方。

## 常见问题

**关掉「提问窗口优化」会怎样？**

回到系统自带的提问卡，界面跟没装这个插件时一样。代价是那张卡不能翻页、不能贴图。

**为什么这次它没问我，直接做完了？**

「提问模式」关着，或者这一轮确实只是汇报结果 —— 两种情况都不该追问。

**贴的图存哪儿？**

本地 `DSH_HOME/attachments` 下面，跟 DSH 自己收的附件放在一起，不上传任何地方。

**答到一半关掉页面会怎样？**

提问会一直挂着等你十分钟；超时之后 AI 当作没答，继续往下走。

**卸载**

```
dsh plugin --profile desktop remove dsh-question-mode
```

## 技术说明

- **座位**：`conversation.input.dock`（提问面板）、`plugins.bundle.config`（设置页）、`conversation.input.attachments`（附件栏）
- **工具**：插件自己注册 `ask_user`，不走系统自带的 `ask_user_question`，所以答案里能带上图片附件
- **本机路由**：`/dsh-question-mode/{state,set,optimized,confirm,pending,answer}`
- **状态文件**：`$DSH_HOME/question-mode.json`（`active` / `optimized` / `confirmFirst`）
- **日志**：`$DSH_HOME/question-mode.log`
- **自测**：`node render-check.mjs`
- 关闭「提问窗口优化」时，`ask_user` 会把问题转交给系统的 `userQuestions` 服务；拿不到该服务就仍用自己的面板，不会卡死。
